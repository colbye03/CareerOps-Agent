# Communication Reconciliation Prompt Template

Reconcile job-search communications into application state.

## Read for

- interview invitations and scheduling
- recruiter calls
- assessments
- deadlines
- hiring-manager or recruiter review
- application acknowledgements
- explicit rejections
- closures
- withdrawals
- referral or role-transfer activity

## Authority

Prefer:

1. user-confirmed or recruiter-confirmed status
2. employer portal
3. employer automated email
4. job-board automation
5. inference

Within the same authority level, prefer the most recent unambiguous event.

Do not classify silence as rejection. Deduplicate reminder emails and repeated automated notices.
